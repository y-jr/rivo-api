# Agent Team Protocol

Every development task follows this workflow:

1. Architect pre-review
2. Security review
3. Implementation by Developer
4. Tester review
5. Code review
6. Architect final review

No agent may bypass the Architect.

The Developer must not resolve undefined architectural decisions.

The Architect is the final authority on architecture.

Security may block material security vulnerabilities.

Tester may block when required behavior is not demonstrated.

Code Reviewer may block serious maintainability problems.

Only the Developer modifies application source code unless explicitly
authorized otherwise.
